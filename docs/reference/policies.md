# policies.md — 정책 체크리스트 경량 참조본

> 원본: PRD v1.3 10-1·12장, 개발설계서 v1.6 4.4.3·4.5.3, 요구사항정의서 v1.1 NFR-SEC/NFR-CMP.
> 이 파일은 세션 시작 시 원본 .docx 대신 먼저 참조한다 (CLAUDE.md 2장). FE-*/API-*/CHAT-*/PGA-* 작업 시 아래 항목을 코드 리뷰 체크리스트로 사용한다.

## 1. Legend 계열 증강체 승률 비노출

- 대상: `augments.is_legend_related=true`
- 이중 방어: (1) 챗봇 프롬프트 컨텍스트 구성 단계에서 `win_rate` 필드 자체를 제외(전처리) (2) 답변 후처리에서 '승률' 주변 숫자 패턴 재스캔 필터
- 웹사이트(FE-06)는 숫자 대신 "승률 표시 안함" 텍스트만 렌더링, DOM에 숫자 자체가 없어야 함
- 담당 TASK: API-05, CHAT-06, FE-06 | 테스트: TEST-00 사전 시나리오 필수

## 2. 상대 플레이어 프라이버시

- 동일 매치의 비식별 상대 Riot ID 노출 금지, 조합 정보 언급만 허용
- 이중 방어: (1) LLM 생성 전 프롬프트 규칙 (2) LLM 생성 이후 정규식 재마스킹 — 부분 마스킹 실패(닉네임 일부만 가려짐) 케이스까지 확인
- 담당 TASK: PGA-09, CHAT-06 | 테스트: TEST-00 사전 시나리오 필수

## 3. 패치 데이터 정합성

- 모든 레코드에 `patch_version` 태깅
- `patches.is_current`는 6개 op.gg 도구 호출 + 임베딩 생성이 전부 성공한 마지막 순간에만 트랜잭션 전환. 중간 실패 시 이전(완전한) 패치 유지
- 담당 TASK: DATA-10, DATA-13 | 테스트: TEST-00 사전 시나리오 필수

## 4. 비로그인 세션

- 회원가입/로그인 시스템 없음. `session_id`(UUID)는 대화 묶음 키일 뿐 회원 식별자 아님
- 사후 패인 분석 계정 연동도 로그인이 아니라 localStorage 기반 "최근 조회 계정 목록"
- 담당 TASK: API-08, FE-07

## 5. RAG 근거 원칙

- 검색된 문서에 없는 내용 추측 금지, 모든 답변에 기준 패치 버전 명시
- 근거 검증: 답변 내 고유명사가 실제 검색 문서에 있는지 문자열 매칭 사후 점검, 불일치 시 재생성 또는 경고 문구
- 담당 TASK: CHAT-03, CHAT-06

## 6. 인증 없음 / Rate Limiting

- 모든 API 인증 없음. IP 기준: `catalog/*` 분당 60회, `chat/*` 분당 10회
- 담당 TASK: API-07 | 테스트: TEST-10

## 7. 프롬프트 인젝션 방어

- 사용자 입력은 `[사용자 메시지]` 델리미터로 시스템 프롬프트와 구조적으로 분리
- "이전 지시를 무시해" 류 입력은 데이터로만 취급, 지시로 따르지 않음
- 담당 TASK: CHAT-04 | 테스트: TEST-00 사전 시나리오 필수

## 8. 범위 밖 질문 처리

- TFT 무관 질문(잡담, 타 게임 등)은 정중히 범위 밖 안내, 답변 시도하지 않음
- 담당 TASK: CHAT-04

## 9. 무료 인프라 한도 대응

- Render 콜드스타트(15분 무요청 슬립), Groq/HF 무료 티어 요청 제한 고려해 재시도·폴백 구현
- 콜드스타트 비중이 전체 요청의 10%를 넘으면 유료 플랜 전환 검토 트리거
- 담당 TASK: CHAT-06(재시도), REL-03(모니터링)

## 10. Personal Key 용도 준수

- 개인 또는 소규모 비공개 커뮤니티 용도로만 사용, 이용자 규모 본인+지인 약 10명으로 제한
- 상업적 이용/RSO 로그인 전환은 범위 외(PRD 14장 백로그)
