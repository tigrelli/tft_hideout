- `frontend/src/components/common/info-tooltip.tsx` 신규: hover(데스크톱)·tap(모바일) 모두 지원하는 정보 아이콘+팝업 공용 컴포넌트(`comp-detail/item-icon-row.tsx`의 hover/pinned 분리 상태 패턴 재사용 — 단일 토글이면 클릭 시 브라우저가 직전에 쏘는 mouseenter와 충돌해 즉시 닫히는 문제가 있어 hover/pinned를 별도 상태로 관리).
