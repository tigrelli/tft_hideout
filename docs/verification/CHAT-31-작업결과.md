## 문제와 실제 원인

- **H13**("티에프티 오구먼트가 뭐임?")과 **H14**("롤체 하이롤 각 어캐 잡음?") 모두 검색 실패로 "확인되지 않았습니다"만 반환.
- H13은 "오구먼트"가 실제 augment 키워드 정규식(`증강체|오그먼트`)의 "오그먼트"와 표기가 달라(구/그) 1차 키워드 매칭 자체가 실패 → 2차 LLM도 애매하게 처리 → 검색 실패.
- H14는 "하이롤"이 이미 CHAT-25에서 오프토픽 2차 LLM 프롬프트에 온토픽 예시로 등재돼 오프토픽으로는 안 걸리지만, **의도분류 2차 LLM에는 general_rules 예시로 "일반 전략 테크닉"이 없어** general_strategy로 분류된 뒤 RAG(comps/augments/item_builds) 의미 검색이 "롤체 하이롤 각 어캐 잡음?" 같은 은어투성이 텍스트에서 좋은 매치를 못 찾고 실패.

## 구현

1. **`chat_preprocessing.py`의 `SLANG_DICTIONARY`에 3건 추가**:
   - `"오구먼트" → "증강체"`(오타/변형 표기 정정 — 정식 명칭으로 고치면 1차 키워드 매칭이 자동으로 걸림)
   - `"어캐" → "어떻게"`(범용 인터넷 은어, 특정 용어 전용이 아니라 여러 질문에 폭넓게 도움)
   - `"롤체" → "TFT"`(범용 구어체 줄임말)
2. **`intent_classification.py`의 2차 LLM 분류 프롬프트(`_SYSTEM_PROMPT`) `general_rules` 카테고리 설명 확장**: 기존엔 "고정 게임 시스템 규칙/메커니즘"만 예시로 들었는데, "특정 메타 데이터가 필요 없는 일반적인 플레이 테크닉·전략 개념 설명(예: 하이롤을 어떻게 준비하는지)"도 포함하도록 넓혔다 — 이렇게 하면 H14 같은 질문이 RAG 검색이 필요 없는 `general_rules`(CHAT-27, LLM 일반 지식 기반 답변)로 라우팅돼, 애초에 은어 섞인 텍스트로 임베딩 검색을 시도할 필요가 없어진다(검색 품질에 의존하지 않는 더 근본적인 해결).

## 한계 및 후속 확인 필요 사항

- H14는 "1차 키워드 매칭 안 됨 → 2차 LLM이 general_rules로 분류함"에 의존하므로, 실제 Groq 2차 분류가 넓어진 카테고리 설명을 얼마나 잘 따르는지는 배포 후 프로덕션 재질의로 최종 확인 필요(CHAT-27~30과 동일한 성격의 한계).
- "어캐"→"어떻게", "롤체"→"TFT"는 특정 용어 전용이 아닌 범용 치환이라, 향후 다른 문맥에서 의도와 다르게 치환될 여지가 이론적으로는 있다(예: "어캐"가 다른 의미로 쓰이는 경우) — 실사용 중 문제가 재현되면 사전에서 제거하거나 문맥 조건을 추가할 것.
- "오구먼트" 외에 다른 흔한 오타·변형 표기(예: "오그멘트")가 더 있을 수 있어 재발 시 사전에 계속 추가하는 CHAT-14/CHAT-19/CHAT-21과 동일한 점진적 보강 방식.
