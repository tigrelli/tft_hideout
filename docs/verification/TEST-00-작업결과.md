## 문서 작성 중 새로 확정한 사항 (원본 문서에 없어 이번에 판단)

원본 문서에 계산식은 있지만 경계 조건이 명시되지 않아, 이번 작업에서 아래처럼 확정했다. PM 승인 시 이 결정도 함께 승인되는 것으로 간주한다.

1. **PGA-04 가중치 기준**: "캐리는 가중치 2, 나머지는 1"의 가중치는 비교 대상 메타 조합(comp)의 `comp_champions.is_carry` 값 기준으로만 정해진다. 플레이어 보드에만 있고 해당 조합에는 없는 챔피언은 가중치 1.
2. **PGA-04 매칭 대상**: 현재 패치의 모든 메타 조합과 비교해 유사도가 가장 높은(이탈도가 가장 낮은) 조합 하나를 `matched_comp_id`로 선택. 동률이면 `comps.play_rate`가 더 높은 쪽 우선.
3. **PGA-05 분모 정의**: "보유 총 완성 아이템 수"는 매칭된 조합 캐리 여부와 무관하게 플레이어 보드 전체 챔피언이 보유한 완성 아이템 총합.
4. **PGA-06 0으로 나누기 방어**: 증강체 미선택은 게임 규칙상 불가능하지만, 방어적으로 `augment_synergy=None` 반환(예외 금지).
5. **PGA-07 검증 범위**: LLM 생성이라 출력 문자열 고정 비교가 불가능하므로, (a) 프롬프트에 점수·등수가 정확히 주입되는지 (b) 후처리가 원 수치 노출/단정적 부정 표현을 걸러내는지만 검증 대상으로 확정.
