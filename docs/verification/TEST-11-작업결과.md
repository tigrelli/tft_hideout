## 채점 기준 요약(정답지 서문 그대로, PM 확인 완료 2026-08-14)

- 정답지는 **채점 기준**이지, 챗봇이 그 문장을 그대로 말해야 한다는 뜻이 아니다.
- **A~D(게임 규칙·챔피언·아이템·랭크)**: 정답지에 실제 사실 기반 "모범답안"이 있음 — 챗봇 답변이 **내용상 일치**하는지가 기준(문장 일치 불필요).
- **F(메타·공략)·E 일부(최신 패치 세부)·G(챗봇 기능)·H(경계/예외)**: 고정 정답 대신 `[채점기준]`/`기대 응답 방향`으로 표기 — "정직하게 한계를 인정하는지", "단정하지 않고 적절히 안내하는지" 같은 **행동 기준**으로 채점.
- 패치마다 바뀌는 세부 수치(챔피언 스킬 수치 등)는 정답지도 "확인 경로(게임 내 정보창, lolchess.gg, op.gg) 안내"를 기대 답변으로 잡아둠 — 챗봇이 "확인되지 않았습니다 + 확인 경로 안내"로 답하면 **정상**이지 버그가 아님.

- **캐시 주의**: CHAT-08 캐시는 (질문 문장 정규화값 + patch_version)을 키로 쓴다. 이미 한 번 물어본 질문을 코드 수정 후 **똑같은 문장으로 재확인**하면 캐시된(수정 전) 답변이 그대로 나와 수정이 반영 안 된 것처럼 보일 수 있다(2026-08-14 CHAT-21 검증 중 실제로 겪음). 특정 질문 캐시만 지우려면:
  ```python
  # backend/.venv 활성화 후, backend 디렉터리에서
  from dotenv import load_dotenv; load_dotenv('/home/tigrelli/projects/tft_hideout/.env')
  import sys; sys.path.insert(0, '.')
  from services.chat_cache import compute_cache_key
  from sqlalchemy import create_engine, text
  from db.session import get_database_url
  key = compute_cache_key("정규화된 질문 텍스트", "17.9")  # 실제 patch_version으로
  engine = create_engine(get_database_url())
  with engine.begin() as conn:
      conn.execute(text("DELETE FROM chat_answer_cache WHERE cache_key = :k"), {"k": key})
  ```
  (로컬 `.env`의 `DATABASE_URL`은 운영 Supabase와 동일 — `docs/verification/CHAT-12-작업결과.md` 정정 각주 참고. 삭제는 캐시 행 1건뿐이라 안전.)
