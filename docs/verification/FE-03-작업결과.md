## 착수 중 발견하고 수정한 버그 2건

1. **백엔드에 CORS 설정이 전혀 없었음**: 실제 브라우저(Playwright)로 배포된 백엔드를 호출해보고서야 발견 — pytest TestClient·curl은 브라우저 CORS 정책을 적용하지 않아 지금까지 아무도 못 봄. 즉 **배포된 프론트엔드가 실제로는 데이터를 하나도 못 받아오는 상태**였음. `backend/main.py`에 `CORSMiddleware` 추가(배포 프론트엔드 오리진 + 로컬 dev, 인증 없는 공개 API라 credentials 없이 오리진만 허용), pytest 3건 추가(backend 175/175 통과) 후 별도 커밋으로 main에 push·배포 완료(PM 승인).
2. **디자인 토큰에 없던 "OP" 티어 발견**: op.gg 실제 응답(`opTier`)에 design-tokens.md 권장안(S/A/B/C)에 없던 `"OP"`(S보다 상위) 값이 실제로 존재함을 확인. 미확정 항목 재량으로 레드 계열(`#D9463D`) 임시 색상 채택, `design-tokens.md`에 발견 사실과 함께 기록(최종 색상은 PM 확인 필요).
